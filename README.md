# 🐦 Flappy Bird — Unity

A 2D arcade game developed with **Unity and C#**, inspired by the classic Flappy Bird gameplay.

## 🎮 About the Game

The player controls a bird and attempts to navigate through obstacles while achieving the highest possible score.

The project was developed as a Unity game development project to practice fundamental gameplay programming concepts and 2D game mechanics.

## ✨ Features

* 🐦 Player movement and input
* 🪽 Flapping/jump mechanic
* 🏗️ Obstacle system
* 💥 Collision detection
* 📊 Score system
* 🔄 Game restart functionality
* 🎮 2D gameplay

## 🛠️ Technologies

* **Engine:** Unity
* **Programming Language:** C#
* **Version Control:** Git / GitHub
